
========================================
Cisco Router IOS and Startup Configuration Backup
Platform: Cisco Packet Tracer
Router: Cisco 2811
========================================

1. Configure Router Interface

Router>enable
Rputer#configure terminal
Router(config)#interface fastethernet 0/0
Router(config)#ip address 192.168.1.1 255.255.255.240
Router(config)#no shutdown
Router(config)#exit

2. Verify IOS Image in Flash

Router#show flash

3. Backup IOS Image to TFTP Server

Router#copy flash tftp

Source Filename:
2800nm-advipservicesk9-mz.151-4.M4.bin

TFTP Server Address:
192.168.1.10

4. Backup Startup Configuration to TFTP Server

Router#copy startup-config tftp

TFTP Server Address:
192.168.1.10

Destination Filename:
Pune-Router-config
