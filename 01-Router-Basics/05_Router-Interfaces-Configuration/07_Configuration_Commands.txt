## Router 2 Configuration 

enable
configure terminal

interface fastethernet 0/0
ip address 180.180.0.1 255.255.255.252
no shutdown
exit

interface fastethernet 0/1
ip address 192.168.1.1 255.255.255.240
no shutdown
exit

end
show ip interface brief
