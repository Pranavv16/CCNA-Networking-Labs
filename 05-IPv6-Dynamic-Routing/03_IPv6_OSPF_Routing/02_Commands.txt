
============================================================
IPv6 OSPFv3 DYNAMIC ROUTING - CONFIGURATION COMMANDS
============================================================

-------------------------
ROUTER R1
-------------------------

enable
configure terminal

ipv6 unicast-routing

interface loopback 1
ip address 1.1.1.1 255.255.255.255
exit

ipv6 router ospf 1
interface fastethernet 0/0
ipv6 ospf 1 area 10
interface fastethernet 0/1
ipv6 ospf 1 area 10

end
