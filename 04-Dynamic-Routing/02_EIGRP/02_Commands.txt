
==================================================
       OSPF DYNAMIC ROUTING CONFIGURATION
             CISCO PACKET TRACER
==================================================

--------------------
ROUTER 1 (R1)
--------------------

! DHCP Configuration

ip dhcp pool R1
 network 10.10.10.0 255.255.255.192
 default-router 10.10.10.1
exit

! OSPF Configuration

router ospf 1
 network 10.10.10.0 0.0.0.63 area 1000
 network 10.10.10.192 0.0.0.3 area 1000
 network 10.10.10.208 0.0.0.3 area 1000
exit

! OSPF Cost Configuration

interface fastethernet 0/0
 ip ospf cost 10
exit


--------------------
ROUTER 2 (R2)
