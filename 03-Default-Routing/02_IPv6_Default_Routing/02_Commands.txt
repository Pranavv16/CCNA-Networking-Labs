
========================================
IPv6 DEFAULT ROUTING
========================================

1. R1 CONFIGURATION
ipv6 unicast-routing

int f0/0
ipv6 address FD00::1/64

int f0/1
ipv6 address 2001::1/64


2. R2 CONFIGURATION

ipv6 unicast-routing

int f0/0
ipv6 address FD01::1/64

int f0/1
ipv6 address 2001::2/64


3. VERIFICATION COMMANDS

show ipv6 interface brief
show ipv6 route



4. CONNECTIVITY TESTING

ping <IPv6 address>
